# Te Whare Tapa Whā Wellbeing Reflection

A Jamstack web app for personal reflection using Te Whare Tapa Whā (Sir Mason Durie).

## What it does

- Guides you through the four dimensions: taha tinana, taha hinengaro, taha wairua, taha whānau
- Lets you score each from 1–5 and add optional notes
- Shows a live radar chart of your shape
- Produces a printable summary

This is a digital interpretation for reflection and conversation. It is not a clinical tool.

## Stack

- HTML, CSS, TypeScript (compiled to plain JS via Vite)
- Static site — deploy the `public/` folder
- Local storage for session persistence
- Pure SVG radar chart (no external chart library)

## Project structure

```
src/
  types.ts        # Domain interfaces and constants
  storage.ts      # LocalStorage persistence layer
  chart.ts        # SVG radar chart renderer
  app.ts          # Main app controller (events, routing, rendering)
  main.ts         # Vite entry point

public/
  index.html      # Static HTML shell
  styles.css      # Responsive, accessible styles
  app.js          # Built output (generated by Vite)

tests/
  unit/
    storage.test.ts   # Storage module tests
    chart.test.ts     # Chart rendering tests
    app.test.ts       # App controller tests
  e2e/
    reflection.spec.ts # Playwright end-to-end tests
```

## Run locally

```bash
npm install
npm run dev
# Open http://localhost:3000
```

## Build for production

```bash
npm run build
# Outputs public/app.js
```

## Deploy

Upload the contents of `public/` to any static host (Netlify, Cloudflare Pages, GitHub Pages, S3, etc.).

## Run tests

```bash
# Unit tests (Vitest + jsdom)
npm test

# End-to-end tests (Playwright)
npm run test:e2e
```

## Cultural note

Te Whare Tapa Whā is a holistic model of hauora. The numeric scores and chart are a visualisation aid only. Meaning belongs to the person reflecting.
